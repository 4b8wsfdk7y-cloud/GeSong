I evaluate LLMs used in social research and build LLM workflows for real
organizations. My main project tests whether a locally run model can stand in
for survey respondents; my internship work built retrieval, structured-output,
and human-review pipelines for enterprise tasks.

| **[SurveyLLM-Eval](https://github.com/4b8wsfdk7y-cloud/cgss-gender-attitude-llm-audit)** | Audits Qwen3.5-9B as a synthetic survey respondent against 31,856 CGSS respondents.
